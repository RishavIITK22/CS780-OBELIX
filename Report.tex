\begin{abstract}
We tackle OBELIX, a warehouse robot POMDP task where an agent must find, attach to, push, and unwedge a grey box to the arena boundary using only binary sonar and IR sensors.
We explored Double DQN, vanilla PPO, PPO with frame stacking, PPO with LSTM, a three-policy hierarchical architecture, GRU-based multi-head PPO, and a final Explicit Phase Belief (EPB) agent that replaces recurrent memory with a hand-crafted non-decaying 16-dimensional belief state.
A key finding was that reward shaping and encoded observations hurt performance compared to raw reward PPO.
The best codabench score of $+157.4$ was achieved by the GRU-based agent trained without reward shaping.
\end{abstract}

\section{Introduction and Problem Description}

OBELIX is a simulated warehouse robot task that requires an autonomous agent to navigate a 2D arena, locate a grey box, attach to it by approaching head-on, push the box to any boundary wall, and handle cases where the box becomes wedged in a corner (the ``unwedge'' phase).
The challenge is designed to be a realistic Partially Observable Markov Decision Process (POMDP): the robot has \emph{no global position or orientation}, and can only observe 18 binary sensor bits: 4 left sonar readings (near/far $\times$ 2 beams), 8 front sonar readings (near/far $\times$ 4 beams), 4 right sonar readings (near/far $\times$ 2 beams), one IR proximity sensor (object at $<4$~inches), and one stuck flag (motor current exceeded threshold).

The task unfolds in three difficulty levels:
\begin{itemize}[noitemsep]
    \item \textbf{Level 1 (static):} The box remains stationary. The robot must find and push it to a wall.
    \item \textbf{Level 2 (blinking):} The box periodically disappears and reappears. Sensors may return false negatives, breaking naive reactive strategies.
    \item \textbf{Level 3 (moving + blinking):} The box drifts autonomously in addition to blinking, making prediction and interception necessary.
\end{itemize}
An optional wall-obstacle variant places internal walls in the arena, requiring collision-aware navigation.

The POMDP nature makes this problem hard: the box may be invisible for hundreds of consecutive steps, the robot cannot localise itself, the phase transitions (find $\to$ push $\to$ unwedge) must be inferred purely from sensor evidence, and exploration is structureless without any global map.
The objective is to maximise mean cumulative reward (per episode, scaled by 5) across all difficulties, with a maximum of 1000 steps per episode.


\section{Approach and Model Evolution}

\subsection{Phase 1: Double DQN Baseline}

\paragraph{POMDP formulation.}
OBELIX is formally a POMDP $\langle \mathcal{S}, \mathcal{A}, \mathcal{O}, T, \Omega, R, \gamma \rangle$.
The true state $s_t \in \mathcal{S}$ includes robot pose, box position, and phase; only observation $o_t \in \{0,1\}^{18}$ is accessible.
The agent must maximise $\mathbb{E}\bigl[\sum_{t=0}^{T} \gamma^t r_t\bigr]$ with $\gamma = 0.99$.

\paragraph{Algorithm.}
The starting point was a Double DQN (DDQN) agent.
DQN approximates the action-value function $Q^*(s,a) = \max_\pi \mathbb{E}\bigl[\sum_{t} \gamma^t r_t \mid s_0{=}s, a_0{=}a\bigr]$ with a neural network $Q(o;\theta)$.
DDQN decouples action \emph{selection} from action \emph{evaluation} to reduce maximisation bias:
\begin{equation}
  y_t = r_t + \gamma\, Q\!\bigl(o_{t+1},\,\arg\max_{a'} Q(o_{t+1},a';\theta);\,\theta^{-}\bigr),
  \label{eq:ddqn}
\end{equation}
where $\theta^{-}$ is a periodically-copied target network.
The network was a three-layer MLP ($18 \to 64 \to 64 \to 5$) with $\epsilon$-greedy exploration; the loss was
$\mathcal{L}(\theta) = \mathbb{E}\bigl[(y_t - Q(o_t, a_t; \theta))^2\bigr]$.

\paragraph{Infrastructure built.}
A vectorised environment (\texttt{vec\_env.py}) ran $N$ OBELIX instances in parallel subprocesses.
A \texttt{RewardShaper} (\texttt{reward\_shaper.py}) defined a shaped reward
\begin{equation}
  \tilde{r}_t = r_t + F(o_t, a_t),
  \label{eq:shaping}
\end{equation}
with sensor-evidence bonuses (find phase), a forward-progress bonus (push), and an escalating stuck penalty.
A \texttt{BeliefStateEncoder} (\texttt{state\_encoder.py}) expanded $o_t \in \{0,1\}^{18}$ into a 49-dimensional frame with sector strengths, direction summaries, and temporal-memory flags.

\paragraph{Failure.}
DDQN with $\tilde{r}_t$ and encoded observations scored $-13{,}931$ on codabench.
Two factors contributed.
First, DDQN's off-policy replay is well-suited to dense-reward tasks; the OBELIX reward is sparse and highly delayed (success bonus only at episode end), making the bootstrapped TD target $y_t$ (Eq.~\ref{eq:ddqn}) extremely noisy early in training.
Second, the shaping term $F$ was not potential-based ($F \neq \gamma\Phi(o') - \Phi(o)$), so it changed the optimal policy~\cite{ng1999policy}: the agent learned to exploit sensor bonuses without completing the task.

\subsection{Phase 2: PPO and the Surprising Benefit of Simplicity}

\paragraph{Algorithm.}
Proximal Policy Optimisation (PPO)~\cite{ppo} directly optimises the policy $\pi_\theta(a \mid o)$ using the clipped surrogate objective:
\begin{equation}
  \mathcal{L}^{\text{CLIP}}(\theta) = \mathbb{E}_t\!\left[\min\!\left(\rho_t(\theta)\,\hat{A}_t,\;\operatorname{clip}\!\left(\rho_t(\theta), 1{-}\varepsilon, 1{+}\varepsilon\right)\hat{A}_t\right)\right],
  \label{eq:ppo}
\end{equation}
where $\rho_t(\theta) = \pi_\theta(a_t \mid o_t)/\pi_{\theta_{\text{old}}}(a_t \mid o_t)$ is the importance ratio and $\hat{A}_t$ is the Generalised Advantage Estimate (GAE):
\begin{equation}
  \hat{A}_t = \sum_{\ell=0}^{T-t-1}(\gamma\lambda)^\ell \delta_{t+\ell}, \qquad \delta_t = r_t + \gamma V_\theta(o_{t+1}) - V_\theta(o_t).
  \label{eq:gae}
\end{equation}
The full PPO loss is
$\mathcal{L} = -\mathcal{L}^{\text{CLIP}} + c_v \mathcal{L}^{\text{VF}} - c_e \mathcal{H}[\pi_\theta]$,
where $\mathcal{L}^{\text{VF}} = \mathbb{E}_t[(V_\theta(o_t)-V^{\text{target}}_t)^2]$ and $\mathcal{H}$ is the policy entropy (exploration regulariser).
A shared-trunk MLP actor-critic was used: $f_\theta: \mathbb{R}^{18} \to \mathbb{R}^{128}$ (two Tanh layers), $\pi_\theta(\cdot \mid o) = \operatorname{softmax}(W_a f_\theta(o))$, $V_\theta(o) = w_v^\top f_\theta(o)$.

\paragraph{Key finding: shaping is harmful.}
Raw PPO (no shaping, raw 18-bit obs) scored $+539.9$; the identical architecture with $\tilde{r}_t$ and encoded observations scored $-111{,}868$.
The mechanism: $F$ in Eq.~\ref{eq:shaping} provides dense per-step signal, so the PPO advantage estimate (Eq.~\ref{eq:gae}) is dominated by $F$-shaped values.
The policy gradient points toward maximising $\sum F$ rather than $\sum r$, pushing the agent into a local optimum of circling near sensor fields without completing the task.

\paragraph{Frame stacking.}
To partially address partial observability, $k$ consecutive frames were concatenated:
$\bar{o}_t = [o_{t-k+1}, \ldots, o_t] \in \{0,1\}^{18k}$,
approximating the history-conditioned policy $\pi(a_t \mid h_t) \approx \pi(a_t \mid \bar{o}_t)$.
This is a $k$-Markov approximation and fails when the box is invisible for $> k$ steps -- common in Levels~2 and~3.
Results on codabench did not clearly improve over the single-frame baseline.

\paragraph{LSTM.}
An LSTM-augmented policy addressed the $k$-Markov limitation by maintaining a hidden state $h_t$ across the full episode:
\begin{equation}
  (h_t, c_t) = \operatorname{LSTM}(o_t,\, h_{t-1},\, c_{t-1}), \qquad \pi_\theta(a_t \mid h_t).
\end{equation}
Training used truncated BPTT over windows of length $T_{\text{bptt}}=512$.
In practice, LSTM gradients decay as $\prod_{\tau} \partial h_{\tau+1}/\partial h_\tau$; older time steps ($>$50--100 steps back) contributed negligible gradient, so the agent still could not reliably retain box direction across blank periods of $200{+}$ steps.
Combined with the shaped reward it produced even worse results, ending Phase~2 with a final submission of $-238.6$.

\subsection{Phase 3: Three-Policy Architecture and GRU Recovery}

\paragraph{Three-policy hierarchy.}
Motivated by the OBELIX paper~\cite{obelix}, Phase~3 implemented a behaviour-decomposed architecture with priority ordering:
\begin{equation}
  b_t = \begin{cases} \texttt{unwedge} & \text{if } \texttt{STUCK} \wedge \texttt{IR} \\ \texttt{push} & \text{if } \texttt{IR} \\ \texttt{find} & \text{otherwise} \end{cases}
  \label{eq:fsm}
\end{equation}
Three independent PPO actor-critic networks $\{\pi^b_\theta\}_{b \in \{\texttt{find},\texttt{push},\texttt{unwedge}\}}$ were trained.
The gradient update for policy $b$ only uses timesteps where $b_t = b$:
\begin{equation}
  \nabla_\theta \mathcal{L}^b = \mathbb{E}_t\!\left[\mathbf{1}[b_t = b]\cdot \nabla_\theta \log \pi^b_\theta(a_t \mid o_t)\cdot \hat{A}_t\right].
\end{equation}

\paragraph{Failure analysis.}
The FSM selector (Eq.~\ref{eq:fsm}) relies on clean sensor readings.
During blinking (Level~2) and while pushing (where \texttt{IR} can flicker), $b_t$ mis-classified frequently, so the push policy received gradients from find-phase timesteps and vice versa -- a form of \emph{policy interference}.
Additionally, $\mathbf{1}[b_t = b]$ masks out the majority of timesteps for each head, starving the gradient signal.
Scores ranged from $-31{,}641$ to $-158{,}772$.

\paragraph{GRU multi-head PPO.}
Replacing hard phase-switching with a unified recurrent agent (\texttt{ppo\_gru.py}):
\begin{align}
  h_t &= \underbrace{(1 - z_t) \odot h_{t-1}}_{\text{retain}} + \underbrace{z_t \odot \tilde{n}_t}_{\text{update}}, \label{eq:gru} \\
  z_t &= \sigma\!\left(W_z [h_{t-1};\, o_t] + b_z\right), \quad
  r_t = \sigma\!\left(W_r [h_{t-1};\, o_t] + b_r\right), \quad
  \tilde{n}_t = \tanh\!\left(W_n [r_t \odot h_{t-1};\, o_t] + b_n\right). \notag
\end{align}
The find/push MLP and GRU-based unwedge head shared training data without any masking.
All reward shaping was removed.
This yielded scores of $-394.2$ (no walls) and $+157.4$ (with walls) -- the best results of the project.

\paragraph{GRU washout (identified failure mode).}
During blank sensor steps, the update gate $z_t \approx \sigma(b_z)$ is small (no informative input), so from Eq.~\ref{eq:gru}:
\begin{equation}
  \|h_{t+T}\| \approx (1 - \bar{z})^T \|h_t\| \xrightarrow{T \to \infty} 0,
  \label{eq:washout}
\end{equation}
where $\bar{z}$ is the mean update-gate activation.
After $T \sim 200$ blank steps the hidden state approaches zero, erasing the last-known box direction.
This is the primary failure mode on Level~2 and Level~3.

\subsection{EPB: Explicit Phase Belief Agent (Final Approach)}

\paragraph{Motivation.}
The GRU washout (Eq.~\ref{eq:washout}) is intrinsic to any recurrent unit with bounded activations.
The EPB agent replaces learned recurrence with an \emph{explicit, non-decaying belief state} $b_t \in \mathbb{R}^{16}$ (\texttt{compact\_belief.py}).

\paragraph{Belief update rule.}
Unlike a GRU, the last-visible direction fields update only when a sensor fires and never decay:
\begin{equation}
  d_t^{\text{dir}} =
  \begin{cases}
    \phi^{\text{dir}}(o_t) & \text{if } \textstyle\sum_i o_t^{(i)} > 0 \quad \text{(sensor active)} \\
    d_{t-1}^{\text{dir}} & \text{otherwise}
  \end{cases}
  \label{eq:belief_update}
\end{equation}
for direction $\text{dir} \in \{\text{left}, \text{front}, \text{right}, \text{IR}\}$, where $\phi^{\text{dir}}$ aggregates the relevant sonar bits.
A staleness counter $\tau_t = \min(\tau_{t-1} + \mathbf{1}[\text{blank}],\, 500)$ and phase latch $\texttt{attached}_t = \texttt{attached}_{t-1} \vee \mathbf{1}[\text{IR active for} \ge 2\text{ steps}]$ complete the 16-dim state.

\paragraph{Network.}
The 39-dimensional policy input is:
\begin{equation}
  x_t = [\,\underbrace{o_t}_{18}\;\|\;\underbrace{b_t}_{16}\;\|\;\underbrace{\phi^{\text{FSM}}(o_t, b_t)}_{5}\,],
  \label{eq:epb_input}
\end{equation}
where $\phi^{\text{FSM}}$ is a one-hot encoding of the reactive FSM action suggestion (orient toward last-seen direction, spin if blind, push if attached) used as a soft prior.

A \textbf{dual-head actor-critic} with a learned soft gate replaces the hard FSM selector:
\begin{equation}
  \mathbf{l}_t = (1 - g_t)\,\mathbf{l}^{\text{find}}_t + g_t\,\mathbf{l}^{\text{push}}_t, \qquad
  g_t = \sigma\!\left(w_g^\top f_\theta(x_t)\right),
  \label{eq:gate}
\end{equation}
with $f_\theta: \mathbb{R}^{39} \to \mathbb{R}^{128}$ (two Tanh layers).
The gate is supervised by a binary cross-entropy auxiliary loss:
\begin{equation}
  \mathcal{L}^{\text{gate}} = -\bigl[\hat{g}_t \log g_t + (1-\hat{g}_t)\log(1-g_t)\bigr], \quad \hat{g}_t = \texttt{env.enable\_push},
\end{equation}
added to the PPO objective with weight $c_g = 0.5$.
This soft gating is continuous and differentiable, resolving the policy-interference problem of the hard FSM.

\paragraph{Curriculum.}
Training used a 6-stage arena curriculum to ensure dense push-head gradients from the start (small arena $\Rightarrow$ box found quickly $\Rightarrow$ gate and push head receive signal early):
\begin{enumerate}[noitemsep]
    \item 300~px arena, static box, 800 episodes
    \item 400~px arena, static box, 1000 episodes
    \item 500~px arena, static box, 1200 episodes
    \item 500~px arena, static + walls, 1200 episodes
    \item 500~px arena, blinking + walls, 1000 episodes
    \item 500~px arena, moving + blinking + walls, 800 episodes
\end{enumerate}

\section{Error Analysis and Discussion}

\paragraph{Level 1 (static box).}
Even on the simplest level, the agent sometimes performs a prolonged spin without navigating toward the box, indicating that the find policy's exploration strategy is sub-optimal when the box is far from the starting position.
The GRU agent mitigates this by maintaining directional memory, but can still lose the box direction after extended blank-sensor periods.

\paragraph{Level 2 (blinking box).}
When the box blinks (disappears for several steps), agents that rely on reactive sensors immediately lose track.
The GRU's hidden state decays toward zero during blank steps -- the ``memory washout'' problem -- causing the agent to behave as if it has never seen the box.
The EPB agent was designed to fix this by storing the last-visible direction in persistent fields, but due to time constraints this agent was not submitted to the final test phase.

\paragraph{Level 3 (moving + blinking).}
A moving box requires the agent to predict and intercept rather than follow.
With only binary sonar readings and no velocity information, this is extremely difficult.
The GRU agent partially compensates via temporal pattern matching in the hidden state, but fails when the box drifts far enough to escape all sensor cones between sightings.

\paragraph{With walls.}
Internal wall obstacles cause the robot to get stuck more frequently.
The \texttt{STUCK} bit (bit~17) provides evidence of collision, but recovering from corner wedging requires backward-and-turn manoeuvres that are not explicitly rewarded.
Interestingly, the GRU agent scored \emph{higher} on the walls variant ($+157.4$) than without walls ($-394.2$), suggesting that walls may sometimes help corral the box toward a boundary.

\paragraph{Limitations and future work.}
\begin{itemize}[noitemsep]
    \item The EPB agent with the full 6-stage curriculum was not fully trained and evaluated on codabench before the deadline.
    \item A recurrent state-space model (RSSM, \texttt{train\_ppo\_rssm.py}) was begun but not completed.
    \item Hyperparameter search was largely manual; Bayesian optimisation could improve results significantly.
    \item The three-policy architecture, inspired directly by the OBELIX paper, was surprisingly ineffective. A softer mixture-of-experts gating might be preferable to hard FSM switching.
\end{itemize}


\section{Conclusion}

The main takeaway of this project is counter-intuitive: in a sparse-reward POMDP, \emph{less engineering is more}.
Hand-crafted reward shaping and feature encoding consistently hurt performance, while raw PPO trained directly on the environment reward achieved scores three orders of magnitude better.
This likely reflects reward hacking: the agent optimises the artificial shaped signal at the expense of the true objective.

The best agent (GRU multi-head PPO, $+157.4$) demonstrates that memory is beneficial for this POMDP -- but the type of memory matters.
Explicit, non-decaying belief states (EPB) are a principled alternative to GRU washout, and the architecture design appears sound; completing the training run is the primary remaining step.

Future directions include: training with model-based RL (RSSM / Dreamer) to learn a latent world model from binary observations, applying curriculum learning more aggressively, and exploring soft gating (mixture of experts) rather than hard FSM phase detection.
